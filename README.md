# White Label Hometask

A blog application built with Next.js.

![white_label](https://github.com/ainkhm/whitelabel_test/blob/main/.github/cover.png?raw=true)

## Features
- SSR Blog Page: A blog page rendered with server-side rendering.
- API Endpoints: Fetch, search, and filter blog posts.
- Pagination: Simple navigation with “Next” and “Previous” buttons.
- Search: Search blog posts by title.
- Category Filter: Filter blog posts by category.
- Post Page: View a blog post with title, image, excerpt, and categories.

### Install

Clone the repository and install dependencies:

```bash
git clone https://github.com/ainkhm/whitelabel_test.git
cd whitelabel_test
npm install 
```

### Tech Stack
- Frontend: **Next.js, Tailwind CSS**
- State Management: **React State**
